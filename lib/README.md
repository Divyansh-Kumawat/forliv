# lib/

Contains all API calls, services, and core library functions.

## Structure
- `api.ts` - Main API client/axios setup
- `*-api.ts` - Feature-specific API functions (e.g., doctors-api.ts, patients-api.ts)
- `stores/` - State management (Zustand stores, context, etc.)
- `auth.ts` - Authentication utilities
- `constants.ts` - Constants and enums
